# X 媒体下载器：紧凑侧栏 UI

## 目标

将扫描和下载操作组织为紧凑、专业的侧栏界面，并将自动滚动设为默认选择。保留现有采集、媒体列表、目录下载及日志行为。

## 布局

1. 顶部品牌行显示产品名与当前任务状态徽章。
2. 状态卡显示媒体总数，以及待下载、完成和不可下载数量。
3. 设置卡包含转推/回复开关，以及手动/自动滚动分段选项；自动滚动默认选中。
4. 主按钮独占一行，根据状态显示开始、停止或下载中；自动滚动暂停/继续作为辅助按钮。
5. 下载卡保留批量下载和两个媒体标签页。列表项明确显示图片、MP4 视频或 HLS 播放清单，并保留原链接与单项下载。
6. 日志改为可折叠的诊断区，默认收起，不挤压列表。

## 交互与兼容性

- 初始扫描使用 `auto`，用户可在开始前切换为 `manual`。
- 现有元素 ID 继续沿用，避免改变面板脚本的消息协议。
- 无可下载项目、不可下载视频、下载失败等状态继续显示原有文字信息。

## 验收

- 新打开面板时自动滚动被选中。
- 任务状态、统计、设置、下载列表和日志均可在窄侧栏内阅读。
- 开始/停止扫描、暂停/继续自动滚动、批量和单项下载的现有行为不变。
