# X 媒体下载器：HLS 转 MP4 设计

## 目标

对已捕获的 X HLS 播放清单，下载最高质量媒体分片并在浏览器本地重封装为 MP4；保留现有直链 MP4 和图片下载。

## 范围

1. 直链 MP4 继续直接写入所选目录。
2. HLS 下载先解析 master playlist，选择带宽最高的变体；若输入已是 media playlist，直接使用。
3. 依次下载媒体分片，使用受控并发并保持输出顺序。
4. 使用本地打包的 `mux.js` 将 MPEG-TS 分片 transmux 为 fMP4，保持原始编码，不重新编码。
5. 面板使用 Worker 执行下载与封装，主线程仅写入目录并更新进度；下载后文件扩展名为 `.mp4`。
6. 检测 `#EXT-X-KEY`、DRM 标记、缺失分片或不支持的编解码时停止并展示原因，不回退成伪造 MP4。

## 架构

- 新增 HLS 解析/下载模块，纯函数负责 playlist 解析与变体选择，便于 Vitest 测试。
- 新增面板 Worker 与本地构建产物；Worker 接收 HLS URL，下载分片并调用 mux.js，按进度向面板回报。
- `panel.js` 根据 `kind === 'hls'` 路由到 HLS Worker，最终以同一目录选择和状态协议保存 `.mp4`。

## 验收

- 含有 MP4 URL 的媒体仍下载为 MP4。
- 含最高码率 HLS 变体的媒体下载为一个可播放的 MP4 文件。
- 下载进度、取消/失败原因在面板可见。
- 加密 HLS 明确显示不支持，不写出不完整文件。
- 所有处理在浏览器扩展本地进行。
