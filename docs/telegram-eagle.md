# Telegram Web K 保存到 Eagle

本功能只在 `https://web.telegram.org/k/` 生效，不影响 X/Twitter 的扫描、下载或 Eagle 导入功能。

打开 Eagle 并重新加载扩展后，Telegram Web K 中已加载的普通图片和普通视频右上角会显示 `E` 角标。点击后，图片会导入 `Telegtam-Picture`，视频会导入 `Telegtam-Video`；首次使用时自动创建这些文件夹。

成功后角标显示“已保存”，同一 Telegram 消息媒体不会重复导入。文件附件、GIF、贴纸、语音、视频消息、受保护或一次性媒体不会出现保存入口。

需要 Eagle 桌面应用正在运行，并已安装本扩展随附的 Native Messaging 助手。
